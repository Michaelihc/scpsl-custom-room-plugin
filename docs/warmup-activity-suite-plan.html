01 — The one HUD language

Color is not decoration. It's a law.

Every lane's hero is a single full-width state line, mirrored into a world light strip. Color carries meaning identically across all four — learn one lane, you read them all.

03 — Inviolable laws

Six rules every lane obeys.

01

Race yourself first

Personal bests are the initial progression loop: “beat your last run”. A global leaderboard will follow in a later phase, not the first implementation.

02

Red is for urgency, not failure

Reserved for the final ~5 seconds. A miss, a loss, a trailing pace are never red.

03

Green means personal best

The hero saturates green only when you beat your own record. One green world-pulse.

04

Round start is a clean handoff

The real round beginning is never a failure — a partial run is closed, not lost.

05

Rewards never touch the round

Cosmetic only. Nothing earned changes role odds, HP, speed, weapons, or spawn.

06

Bilingual, one voice

EN + CN from a single server flag, in the shipped 莺歌傲然 TMP style. Never stacked.

The one invariant to validate first

Round start must idempotently destroy and disarm every hazard — the SCP-018, any granted weapon or dropped pickup, all HSM IDs, every pooled toy and light — inside the pre-assignment path, before Tutorial players flip to None, from any activity phase, with zero leak into the live round. Everything else is cosmetic; this is the one correctness rule the whole suite rests on.
