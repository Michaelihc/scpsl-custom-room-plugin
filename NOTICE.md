# Attribution

The early-round SCP replacement feature is a LabAPI adaptation of the SCPReplacer mechanic:

- Original concept and plugin: **Jon M** ([jmoore34/ScpReplacer](https://github.com/jmoore34/ScpReplacer))
- Modern EXILED rewrite used as the behavioral reference: [Augaton/SCPReplacer](https://github.com/Augaton/SCPReplacer)

This repository's implementation is integrated with WarmupScpSelector's lifecycle, configuration,
bilingual text, stable-identity rules, and headless tests. It additionally enables living non-SCP
volunteers by default and revalidates the vacancy immediately before assigning the replacement role.
